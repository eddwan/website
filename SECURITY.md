# Segurança

Achou uma falha de segurança no site ou neste repositório (por exemplo, um segredo exposto ou um jeito de alterar o deploy)? **Não abra uma issue pública.**

Use o relato privado do GitHub: aba **Security** → **Report a vulnerability** ([link direto](https://github.com/eddwan/website/security/advisories/new)). A resposta vem em até 7 dias.
